# 🚲 Bike Rental Demand Prediction

## Project Overview

This project predicts bike rental demand using machine learning.

The project uses weather and time-related conditions to estimate the expected number of bike rentals.

## Project Objective

The objective of this project is to build a machine learning model that can predict bike rental demand and integrate the trained model into an interactive prediction application.

## Machine Learning Model

A Linear Regression model was trained to predict bike rental demand.

The model uses features related to:

- Season
- Year
- Month
- Hour
- Holiday
- Weekday
- Working Day
- Weather Situation
- Temperature
- Feeling Temperature
- Humidity
- Wind Speed
- Day

## Prediction Application

An interactive Bike Rental Demand Prediction application was developed.

Users can enter weather and time conditions and receive a predicted bike rental demand from the trained machine learning model.

## Application Features

- Interactive user inputs
- Weather and time conditions
- Trained machine learning model integration
- Bike demand prediction
- Multiple test scenarios
- Clear prediction results

## Testing

The application was tested using different combinations of:

- Season
- Month
- Day
- Hour
- Weather
- Temperature
- Humidity
- Wind Speed
- Working Day

The application successfully generated predictions for the test scenarios.
